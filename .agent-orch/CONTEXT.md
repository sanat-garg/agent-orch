# Project Context

_What the code doesn't say. History: JOURNAL.md. Bugs: AUDIT.md. Mobile HIG rows: UI-REVIEW.md. Cluster: CLUSTER.md. Computer work: AGENTIC.md. CLI flags/stream formats: AGENTS.md. Setup: README.md. Each module's header comment explains its job and API: read it first._

## Architecture (cross-module rules)
- Head = `server.mjs` (http + ws, sessions, chat via the Agent SDK `query()`, serves `public/`) + `orchestrator.mjs` (node:sqlite `data/orchestrator/agent-orch.db`; planner / work / reflection loop; `createOrchestrator({config})` overrides CFG in tests). Queue order = `tasks.position`; plan/reflect/user tasks and deadlines < 24 h jump ahead. Done-when runs through `taskrun.mjs extractCommand`.
- Agents (`agents.mjs`): claude via SDK, codex via `codex exec --json`; `agentStatus` gates routing. Model lists come only from each CLI (`models.mjs`, cached daily). Every discovery/limit/sign-in helper goes through `helpers.mjs runHelper`; never add raw execFile/spawnSync helpers. Limits are per agent and never polled.
- Routing `resolveRoute`: task agent/model → project route → global route → Claude on project.model; unavailable agents fall back to Claude with `tasks.route_note`. Sessions resume only on the agent and node that made them. Delegation (`delegate.mjs`) moves a task only if its `tasks.fallbacks` snapshot is non-empty; UI wording only from app.js `modelStatus(task)`.
- Owner controls: pause/resume/handoff set `stopIntents`, applied by `applyStopIntent` only when the run ended requeued. Owner messages during a plan task go through `deferMessage`; a paused project keeps its queued plan task until resumed (soham's #96 is one, not a bug).
- Worktrees (`worktrees.mjs`): work tasks run in `<repo>/../.agent-orch-worktrees/<repo>-task-<id>` on branch `agent-orch/task-<id>`, sharing main's node_modules; boot prunes orphan task dirs. Only `mergeTask` touches the main tree, under `serialGit`; a rebase conflict → `needs_integration` + an integrator task (`tasks.integrates`) reusing the owner's worktree, and a merge deletes the owner's origin branch. JOURNAL.md merges `merge=union`. `tasks.files` (NULL = everything) + `filesOverlap` decide what runs in parallel.
- Slots (`parallel.mjs`, kv `parallel_settings`): the controller runs 2 only with MemAvailable > 2.5 GB and swap < 25% (`AGENT_ORCH_MEMINFO` = fixture in tests); `memGuard` aborts the newest work task under 300 MB. `kind='review'` tasks never run (`armCheckpoints()` parks them in `awaiting_review`).
- Placement: a work task goes to the free online worker with the agent signed in and most headroom, else the controller; `tasks.run_on` pins one. Plan/reflect/integrators, tasks with a live local worktree and projects without an https/ssh origin stay local. Lost jobs requeue with `[lost]` + a handoff from the pushed WIP branch.
- Cluster: `cluster-protocol.mjs` holds the wire format, `FEATURES` and `WORKER_ACCEPTS`; change it first, CLUSTER.md follows. `cluster.mjs` (hub, node id `controller`): a disk drain (< 2 GB) lifts itself at ≥ 3 GB free, any other drain only the owner lifts; workers self-update once idle when > 20 commits behind. `worker.mjs` is compute-only and must never import server/orchestrator/cluster/runtimes: shared code goes in taskrun.mjs (test/compute-only.test.mjs walks the import graph).
- Extensions (`extensions.mjs`) reach runs via files, never argv; workers get the same bundle per job.
- Browser tasks (`capabilities: ["browser"]`, `browser.mjs`) run the pinned `@playwright/mcp` on a persistent profile, on the controller only with `controllerBrowser`, one running task per identity. The approval gate (`gate.mjs`, `approvals.mjs`) holds outbound MCP calls for the owner and logs to `<DATA>/audit/`; proxy ↔ host talk only through files.
- `public/`: vanilla JS SPA (app.js ~7k lines, then files/stats/ext/browser.js) loaded as classic scripts, so top-level names share one namespace (ui-static.test.mjs rejects duplicate functions). Reuse `toast`, `renderFallbackEditor`, `withUntil`, `fmtDur`. #orchBar stays minimal; everything else lives in the gear's Settings sheet.
- Restart: `POST /api/restart-when-idle` drains the orchestrator, waits for chat turns, preflights HEAD (`restartPreflight`: `node --check` + a throwaway `CW_NO_ORCHESTRATOR=1` boot; a failure stays up and skips that HEAD), exits 0 and systemd boots the new code. Opt-in kv `parallel_settings.autoRestart` starts the same drain (`startRestartDrain`) once `git diff <bootCommit>..HEAD` lists server files (root `*.mjs`, `bin/`, `package*.json`); a cancel skips that HEAD.

## Conventions
- ESM `.mjs`, no build step, no framework, minimal deps. Match the terse style and comment density.
- Tests: `npm test` (bin/test.mjs, private TMPDIR, one suite per machine via flock) runs only the test files the diff from main can reach; `npm test -- test/x.test.mjs` runs named files, `npm run test:full` runs everything (reflection only). Verify a task with the files you touched; the orchestrator runs Done-when itself. Copy a neighbouring test's setup (server tests spawn server.mjs on a free port with a temp `CW_DATA_DIR`; scheduling tests use `createOrchestrator` with a fake `query`; UI tests use playwright-core).
- Times: events carry `until` (epoch s); app.js `withUntil` formats in the browser. Never format times on the server except in logs.
- AUDIT.md items get `**Fixed**` + a one-line note; UI-REVIEW.md rows are marked fixed in place.
- Mobile: Apple HIG (apple-design skill). Modals need `grid-template-columns: minmax(0, 100%)` (test/ui-away.test.mjs). 44px touch targets and 16px fields (iOS zooms smaller ones) go in `@media (pointer: coarse)` blocks placed after the base rule they override (same specificity; sheets load app, files, stats, ext, browser); phone type sizes in the `max-width: 600px` block at the end of app.css. Filled buttons use `--accent-strong` (test/ui-contrast.test.mjs asserts ≥ 4.5:1 in both themes).
- macOS shell scripts must parse under bash 3.2 (test/install-macos-bash32.test.mjs): ship functions with `cmd <<EOF`, not `cat <<EOF | cmd`; under `set -u` an empty `"${arr[@]}"` is unbound; no `declare -A`, `mapfile`, `${x,,}`, `|&`, `local -n`.

## Decisions (beyond BRIEF.md)
- Subscriptions only: API_ENV stripping in server.mjs is what enforces it. Never weaken that.
- Local branch `backup/pre-agent-orch` must never be pushed. Local `claude/*` branches and `agent-orch/task-197/-199/-209` (unlanded partial work) are the owner's: never land or delete them unasked.
- `after` is for TRUE prerequisites only (cancelling cascades). Use `files` to keep parallel work apart.
- System font stack only. No benchmark ranking of models, ever.
- Computer work follows AGENTIC.md's rollout (files-only workspace first). The owner cancelled the Gmail connector (#259, 2026-09-28); don't queue connectors until asked.

## Gotchas
- This checkout IS the live app. Never restart/kill it or call `POST /api/restart-when-idle` on port 3000. Test instances MUST use another port and `CW_DATA_DIR=$(mktemp -d)`. Server/orchestrator edits go live only on restart: a failing Done-when may be stale running code, and new DB tables don't exist until then.
- The verifier runs every command-like backtick snippet in Done-when, joined with ` && `; `>` and `curl` are refused. Absence checks use `! grep …`. A `|` inside a quoted grep pattern is regex, not a pipe.
- /tmp is a small tmpfs with a per-user quota; run heavy tests with `TMPDIR=` on the home disk. test/helper-kill.test.mjs is racy under load and can leave `test/fixtures/helper-parent.mjs` running, hanging the shared test lock: kill that pid.
- `bin/agent-smoke.mjs` and `bin/orch-e2e.mjs` cost quota; never send Claude logout (`confirm: true`) in tests.
- Other sessions and orchestrator auto-commits touch the live checkout at once: re-read before editing. A branch failing in files you didn't touch is usually a stale snapshot base: fast-forward the worktree to main and re-run.
