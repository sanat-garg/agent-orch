# Project Context

_Durable knowledge for every session. History: JOURNAL.md. Bug backlog: AUDIT.md. Mobile HIG findings: UI-REVIEW.md. Cluster design: CLUSTER.md. Computer-work agents (goal 12: gate, connectors, browser, approvals): AGENTIC.md. CLI flags and stream formats: AGENTS.md._

## Architecture (head)
- `server.mjs`: node:http + `ws`; login/sessions (cookie `__Host-cw_session` over HTTPS, `cw_session` on http), chat via the Agent SDK `query()`, serves `public/`. PORT 3000. Chat runtimes end only via `retireRuntime` (runtimes.mjs). Refuses to start on a paired worker (role.mjs) unless `AGENT_ORCH_WORKER_JOB` is set.
- `orchestrator.mjs`: node:sqlite DB `data/orchestrator/agent-orch.db`; planner / work / reflection loop; `runAgent()` wraps adapters with timeout + run log; prompts inline. `createOrchestrator({config})` overrides CFG in tests. Deps: `task_deps` + `all_deps` view. Queue order = `tasks.position` per project; plan/reflect/user tasks and deadlines < 24 h jump ahead.
- `agents.mjs`: adapter registry (`AGENTS`, `runAgentCli`): claude (SDK) and codex (`codex exec --json`) only, sharing `spawnJsonl`. Normalisers must never emit `{}`/`""` when the native event had data (test/empty-events.test.mjs). `agentStatus` (on PATH + logged in, cached 60 s) gates routing.
- `models.mjs`: model lists come only from each CLI (`discoverModels`), cached `<DATA>/models.json`, rediscovered once a day or after a sign-in change; `modelCatalog`/`modelNames` never discover. Never hardcode a model list.
- `helpers.mjs`: every discovery/limit/sign-in helper runs through `runHelper`/`helperOut`/`runHelperSync`/`claudeHelperSpawn` (own process group, SIGTERM→SIGKILL, watchdog, single-flight per agent+account). Never add raw execFile/spawnSync helpers.
- Routing `resolveRoute`: task agent/model → project route → global route → Claude on project.model. Unavailable agents fall back to Claude with `tasks.route_note`. Sessions resume only on the agent and node that made them.
- Limits are per agent (`limitScope`, `blockedUntilFor(agent)`; kv `blocked_*` with `:<agent>` suffix for codex). Nothing polls limits: only the usage card's refresh (`POST /api/limits/:id/refresh`) checks one agent; Claude runs report limits as they go. `usage.mjs` = `<DATA>/metrics/usage.jsonl`; `health.mjs` builds Connections `health`.
- Delegation `delegate.mjs`: a task moves only if its `tasks.fallbacks` snapshot is non-empty; `nextModel` picks the first entry that is connected, listed, unblocked and under 90% of a window. Lists: `convo.fallbacks` per chat, kv `reflect_settings` for reflection. Moves append to `tasks.moves`; UI text only from app.js `modelStatus(task)`.
- Owner controls: pause/resume/handoff set `stopIntents`, applied by `applyStopIntent` only when the run ended requeued. Paused keeps session + worktree and pins agent/model. Remote tasks can be paused but not handed off while running.
- Planner: `planTurn` runs on the chat's agent; owner messages during a plan task go through `deferMessage`.
- Worktrees (worktrees.mjs): work tasks run in `<repo>/../.agent-orch-worktrees/<repo>-task-<id>` on branch `agent-orch/task-<id>`. Only `mergeTask` touches the main tree, under `serialGit` (squash, rebase, ff-only, push); a rebase conflict → `needs_integration` + an integrator task. JOURNAL.md merges `merge=union`. `tasks.files` (NULL = everything) + `filesOverlap` decide what may run in parallel.
- Slots (parallel.mjs): kv `parallel_settings` `{parallelTasks, controllerWork, maxTasks}`. The controller runs 2 only with MemAvailable > 2.5 GB and swap < 25% (`AGENT_ORCH_MEMINFO` = fixture in tests); < 800 MB → no claims; < 300 MB for 30 s → `memGuard` aborts the newest work task. With workers online and `controllerWork` false, remotable tasks are left to workers. `capacityView` sums controller + worker slots.
- `resources.mjs`: /proc snapshot every 10 s and the reaper (`AGENT_ORCH_REAPER=on|dry|off`; never live server/task/chat/terminal processes; ownership via env `AGENT_ORCH_OWNER=<server pid>:task|chat:<id>`).
- Review breaks: `kind='review'` tasks never run; `armCheckpoints()` moves one whose deps are done to `awaiting_review`; approve → done; request-changes queues a fix task into its deps.
- `connections.mjs`: web sign-in runs each CLI's login in tmux (socket `agent-orch-login`, killed on every boot) and scrapes the pane. `remote-login.mjs`: `?node=<id>` on /api/connections* proxies login to a worker. Rows carry `sharedWith` (same account = shared limits).
- `extensions.mjs` (Settings → Skills & tools, `public/ext.js`): skills go where the CLIs find them (`~/.claude/skills/<name>/`, `~/.codex/skills/<name>/`), subagents to `~/.claude/agents/`; MCP servers and personas in `<DATA>/extensions/` (0600, secrets masked). MCP reaches runs via files, never argv (Claude `extraArgs {'mcp-config'}`, codex `-p agent-orch` before `exec`). Persona = `convo.persona`, added via `withPersona` to chat/planner/task/remote-job system text. Remote workers get the persona only (skills/subagents/MCP sync is on branch `claude/heuristic-visvesvaraya-d78c0d`, not yet merged).
- Browser capability (`browser.mjs`): tasks with `capabilities: ["browser"]` (tasks.capabilities + tasks.browser_identity) get the pinned `@playwright/mcp` via a per-run MCP file/codex profile (`ext.mcpRun(agent, {browser})`; workers pass it as the run's `mcp`), profile `~/.agent-orch-browser/profiles/<identity>`, `--output-dir` = the run's .agent-orch/shots, `--executable-path` = any found Chromium (Playwright's cache revision may differ from the MCP's), `--no-sandbox` on Linux. `BROWSER_SYSTEM` is appended to every browser run (resumes too). `place`: only workers with `inventory.browser.capable`, controller only with parallel_settings `controllerBrowser`, one running task per identity (DB-based). The worker's `ensureBrowser` installs Playwright Chromium when none is found (`AGENT_ORCH_WORKER_BROWSER=off|check|install`, check-only under node:test). This is the simple precursor of AGENTIC.md's gate/browserd design.
- Live browser view (`browser-live.mjs` node side, `browser-view.mjs` head fan-out, `public/browser.js`, sidebar globe → Browser sheet): one Chromium per profile with a DevTools port (its `DevToolsActivePort` in the profile), started by a viewer or by a browser run's MCP shim `bin/browser-mcp.mjs` (browserServer wraps the Playwright MCP in it; it rewrites the MCP to `--cdp-endpoint` and marks `<browserRoot>/control/<id>.active`). Take-over = file `control/<id>.takeover`: the shim holds every `tools/call` while it exists; closing the viewer hands back. Workers serve it via `screen.*` frames (feature `screen`). `AGENT_ORCH_BROWSER_HOME` moves the profiles root in tests. CDP key events need `windowsVirtualKeyCode` from the physical key (`.` as 46 is Delete).
- `stats.mjs` + `public/stats.js`: GET /api/stats returns raw records (own read-only DB, cached 30 s); the browser slices. `media.mjs`: screenshots at `<DATA>/media/<sha256>.<ext>`; `bin/shot.mjs` takes them. `github.mjs`: gh wrapper; every project gets a private repo on `origin`.
- `public/`: vanilla JS SPA (app.js ~6.9k lines, marked + dompurify), PWA. Shared helpers: `toast`, `renderFallbackEditor`, `withUntil`, `fmtDur`. Check for name clashes before adding functions (a later declaration silently wins). #orchBar stays minimal (dot + word + Queue + Pause); everything else is in the gear's Settings sheet.
- Live setup: systemd units agent-orch, agent-orch-shell (ttyd 127.0.0.1:7682, Caddy `/shell/`), agent-orch-tmux. `data/` (gitignored) holds auth, convos, metrics, logs, DB, run logs.

## Architecture (cluster)
- `cluster-protocol.mjs`: wire format, validators, pairing/token helpers, `FEATURES` (newer frame types go only to peers listing the feature in hello/welcome), `WORKER_ACCEPTS` (the only frames a worker acts on; hub `send` throws otherwise). Change the protocol here first; CLUSTER.md follows the module.
- `cluster.mjs` (hub): `nodes` + `pairings` tables (codes hashed, multi-use, 1 h), bearer-token WS at `WS_PATH`, local node id `controller`; `listNodes()`/`send()`/`onMessage()`/`version()`. `HEALTH` auto-drain rules; workers self-update once idle when > 20 commits behind. `CW_CLUSTER_HEARTBEAT_MS` shortens liveness in tests. `power.mjs`: Mac battery/sleep policy; `resources.intake.ok === false` shows a node as paused.
- `worker.mjs` (compute-only: `pair`/`run`/`status`/`limit`), home `~/.agent-orch-worker` (`AGENT_ORCH_WORKER_HOME`). Must never import server/orchestrator/cluster/runtimes (shared code goes in taskrun.mjs; test/compute-only.test.mjs walks the import graph). `cap.mjs`/`worker-cap.mjs`: the local cap; every job runs through `<home>/run` (systemd scope or nice; tests set `AGENT_ORCH_WORKER_LIMITER=nice`). `worker-status.mjs`: `worker.sock` is the only listener allowed. `node-metrics.mjs`: `<DATA>/metrics/nodes/<id>.jsonl`.
- Placement (orchestrator `place`/`runRemote`/`remoteJob` via `orch.attachCluster`): `claimNext` → `{task, node, prevNode}`; a work task goes to the free online worker with the agent signed in and most headroom (`nodeCap`), else the controller. Only `remoteWork` tasks go remote: plan/reflect/integrators, tasks with a live local worktree and projects without an https/ssh origin stay local. On job.done the head fetches `agent-orch/task-<id>` (tip must equal job.done.sha) and runs `mergeTask`. Streams replay via `job.attach {from}`; lost jobs (grace `nodes.grace_ms`) requeue with `[lost]` + a handoff from the pushed WIP branch; remote tasks survive a head restart (`adopt`).
- Install + UI: Machines → "Add machine" (app.js `AM`) shows `curl …/install/worker-{linux,macos}.sh | bash -s -- --controller … --code …` (served pre-auth from bin/install-worker*.sh, both `--dry-run`) and watches GET /api/cluster/pair/:code. macOS runs the worker as user `agentorch` from a LaunchDaemon. Machines view: one card per node (`max_slots` 0 = Auto, drain, remove), diagram `CA`, node modal `ND`.

## Conventions
- ESM `.mjs`, no build step, no framework, minimal deps. Match the terse style and comment density.
- Tests: `npm test` (bin/test.mjs, private TMPDIR, one suite per machine via flock) runs only the test files the checkout's diff from its merge-base with main can reach (bin/test-select.mjs: imports, plus files a test names in strings; docs-only → none; package.json or the runner → all; browser/playwright tests only for public/ or test/ changes). `npm test -- --list` shows the pick, `npm test -- test/x.test.mjs` runs named files, `npm run test:full` runs everything. Verify a task with the test files you touched; the orchestrator runs Done-when itself. Reflection starts with `npm run test:full` and queues a fix for any failure ahead of other work (it is the only full run). Server tests spawn server.mjs on a free port with `CW_DATA_DIR` = temp dir; `CW_NO_ORCHESTRATOR=1` serves read APIs without the tick loop. Scheduling tests run `createOrchestrator` in a child with a fake `query` and `config: { pollMs: 100 }`, polling with `test/helpers/wait.mjs`. CLI adapters use stubs in test/fixtures/. Browser tests (test/ui-*.test.mjs) use playwright-core. Worker tests run worker.mjs against an in-process hub (worker CLI calls must be async), pass `health: {diskMinBytes: 0}`, point `AGENT_ORCH_WORKER_SRC` at a scratch repo, fake a Mac with `AGENT_ORCH_WORKER_POWER` + `AGENT_ORCH_WORKER_CAFFEINATE`.
- Times: events carry `until` (epoch s); app.js `withUntil` formats in the browser. Never format times on the server except in logs.
- AUDIT.md items get `**Fixed**` + a one-line note; UI-REVIEW.md rows are marked fixed in place.
- Mobile: follow Apple HIG (apple-design skill). Modals need `grid-template-columns: minmax(0, 100%)`; test/ui-away.test.mjs checks every modal fits 375×667 and 390×844.
- Shell scripts for macOS must parse under bash 3.2 and be tested with `~/.local/opt/bash-3.2.57/bin/bash` (built by bin/dev/build-bash32.sh; test/install-macos-bash32.test.mjs). Tests load installer functions with `AGENT_ORCH_INSTALLER_NO_MAIN=1` (never `${BASH_SOURCE[0]}`).

## Decisions
- Chat and agents run on subscriptions, never API credits (API_ENV stripping in server.mjs). Never weaken that.
- Claude Code and Codex are the only agents; Antigravity, OpenCode, Kiro and Copilot were removed for good.
- Repo is github.com/sanat-garg/agent-orch with fresh history; local branch `backup/pre-agent-orch` must never be pushed.
- `after` is for TRUE prerequisites only (cancelling cascades). Use `files` to keep parallel work apart.
- System font stack only; no bundled web fonts. Delegation = owner-entered fallback lists only; no benchmark ranking.
- Workers are compute-only: terminal status view and local cap are their only local surface.
- Nothing polls the CLIs on a timer: limits on demand, model lists once a day.

## Gotchas
- This checkout IS the live app. Never restart/kill it or call `POST /api/restart-when-idle` on port 3000. Test instances MUST use another port and `CW_DATA_DIR=$(mktemp -d)`.
- Server/orchestrator edits go live only on restart ("Restart when idle" banner). A failing Done-when may be stale running code.
- The verifier runs every command-like backtick snippet in Done-when, joined with ` && `. Commands containing `>` or `curl` are refused. Absence checks use `! grep …`; avoid `|` inside a quoted grep pattern in a "prints nothing" check.
- /tmp is a small tmpfs with a per-user quota (EDQUOT); run heavy tests with `TMPDIR=` on the home disk (the dir must exist). Tests that bypass `npm test` leak `codex-test*` dirs into /tmp.
- test/helper-kill.test.mjs is racy under load and can leave `test/fixtures/helper-parent.mjs` running, hanging `npm test` and the shared test lock. Kill that pid.
- Playwright `hover()` scrolls the target into view; tooltips that hide on scroll flicker on this 1-core box (stats.js `wireTips` re-targets instead).
- Claude logout needs `confirm: true`; never send it in tests. `bin/agent-smoke.mjs` and `bin/orch-e2e.mjs` cost quota.
- `#lbView` needs `contain: size`. Don't commit macOS `._*` files.
- bash 3.2 (macOS /bin/bash): `declare -f` prints `cat <<EOF | cmd` with `| cmd` after the EOF line, so functions shipped via `bash -c "$(declare -f)"` must use `cmd <<EOF`. Under `set -u` an empty `"${arr[@]}"` or `"${BASH_SOURCE[0]}"` (piped script) is unbound. No `declare -A`, `mapfile`, `${x,,}`, `|&`, `;;&`, `local -n`.
- Other sessions and orchestrator auto-commits touch the live checkout at once: re-read before editing, keep shared test edits minimal. A branch failing in files you didn't touch is usually a stale snapshot base: fast-forward the worktree to main and re-run.
