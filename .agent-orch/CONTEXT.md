# Project Context

_Durable knowledge for every session. History: JOURNAL.md. Bugs: AUDIT.md. Mobile HIG findings: UI-REVIEW.md. Cluster: CLUSTER.md. Computer work: AGENTIC.md. CLI flags and stream formats: AGENTS.md. Setup: README.md. Every module opens with a header comment that explains it: read that before changing the module. This file holds only what the code doesn't say._

## Architecture (cross-module rules)
- Head = `server.mjs` (http + ws, sessions, chat via the Agent SDK `query()`, serves `public/`) + `orchestrator.mjs` (node:sqlite `data/orchestrator/agent-orch.db`; planner / work / reflection loop; `createOrchestrator({config})` overrides CFG in tests). Queue order = `tasks.position`; plan/reflect/user tasks and deadlines < 24 h jump ahead. Done-when runs through `taskrun.mjs extractCommand`.
- Agents (`agents.mjs` registry `AGENTS`): claude via SDK, codex via `codex exec --json`. `agentStatus` (on PATH + signed in, cached 60 s) gates routing. Model lists (`models.mjs`) come only from each CLI, cached in `<DATA>/models.json`, refreshed once a day or after a sign-in change. Every discovery/limit/sign-in helper goes through `helpers.mjs` (`runHelper` family); never add raw execFile/spawnSync helpers.
- Routing `resolveRoute`: task agent/model → project route → global route → Claude on project.model; unavailable agents fall back to Claude with `tasks.route_note`. Sessions resume only on the agent and node that made them. Limits are per agent and never polled: the usage card's refresh checks one agent, Claude runs report limits as they go.
- Delegation (`delegate.mjs`): a task moves only if its `tasks.fallbacks` snapshot is non-empty; `nextModel` picks the first entry that is connected, listed, unblocked and under 90% of a window. Lists: `convo.fallbacks` per chat, kv `reflect_settings` for reflection. UI wording only from app.js `modelStatus(task)`.
- Owner controls: pause/resume/handoff set `stopIntents`, applied by `applyStopIntent` only when the run ended requeued. Owner messages during a plan task go through `deferMessage`; a paused project keeps its queued plan task until resumed (project 3's #96 is one, not a bug).
- Worktrees (`worktrees.mjs`): work tasks run in `<repo>/../.agent-orch-worktrees/<repo>-task-<id>` on branch `agent-orch/task-<id>`. Only `mergeTask` touches the main tree, under `serialGit`; a rebase conflict → `needs_integration` + an integrator task (`tasks.integrates`) that reuses the owner task's worktree. JOURNAL.md merges `merge=union`. `tasks.files` (NULL = everything) + `filesOverlap` decide what runs in parallel.
- Slots (`parallel.mjs`, kv `parallel_settings`): the controller runs 2 only with MemAvailable > 2.5 GB and swap < 25% (`AGENT_ORCH_MEMINFO` = fixture in tests); `memGuard` aborts the newest work task under 300 MB. `kind='review'` tasks never run; `armCheckpoints()` parks one whose deps are done in `awaiting_review`.
- Extensions (`extensions.mjs`): MCP servers and personas live in `<DATA>/extensions/` (0600) and reach runs via files, never argv. Workers get the same bundle per job (`ext.sync`).
- Browser tasks (`capabilities: ["browser"]`, `browser.mjs`) run the pinned `@playwright/mcp` on a persistent profile (`AGENT_ORCH_BROWSER_HOME` in tests): on workers with `inventory.browser.capable`, on the controller only with `controllerBrowser`, one running task per identity. The approval gate (`gate.mjs`, `gate-proxy.mjs`, `approvals.mjs`) classifies MCP calls read/draft/outbound, holds outbound ones for the owner and logs to `<DATA>/audit/`; proxy ↔ host talk only through files; held time doesn't count toward the timeout. Live view (`browser-live.mjs`): one Chromium per profile; a take-over file makes the run's MCP shim hold every call.
- `public/`: vanilla JS SPA (app.js ~7k lines, then files/stats/ext/browser.js) loaded as classic scripts, so top-level function names share one namespace and a later declaration silently wins (ui-static.test.mjs now fails on a duplicate). Reuse `toast`, `renderFallbackEditor`, `withUntil`, `fmtDur`. #orchBar stays minimal (dot + word + Queue + Pause); everything else lives in the gear's Settings sheet.
- Cluster: `cluster-protocol.mjs` holds the wire format, `FEATURES` (newer frames go only to peers listing the feature) and `WORKER_ACCEPTS`; change it first, CLUSTER.md follows. `cluster.mjs` (hub, node id `controller`): a disk drain (< 2 GB) lifts itself at ≥ 3 GB free, any other drain only the owner lifts; workers self-update once idle when > 20 commits behind. `CW_CLUSTER_HEARTBEAT_MS` shortens liveness in tests.
- `worker.mjs` is compute-only (`pair`/`run`/`status`/`limit`; home `AGENT_ORCH_WORKER_HOME`) and must never import server/orchestrator/cluster/runtimes: shared code goes in taskrun.mjs (test/compute-only.test.mjs walks the import graph). Tests set `AGENT_ORCH_WORKER_LIMITER=nice`.
- Placement: a work task goes to the free online worker with the agent signed in and most headroom, else the controller; `tasks.run_on` pins one. Plan/reflect/integrators, tasks with a live local worktree and projects without an https/ssh origin stay local. On job.done the head fetches the task branch (tip must equal job.done.sha) and runs `mergeTask`. Lost jobs requeue with `[lost]` + a handoff from the pushed WIP branch; remote tasks survive a head restart.

## Conventions
- ESM `.mjs`, no build step, no framework, minimal deps. Match the terse style and comment density.
- Tests: `npm test` (bin/test.mjs, private TMPDIR, one suite per machine via flock) runs only the test files the diff from main can reach; `--list` shows the pick, `npm test -- test/x.test.mjs` runs named files, `npm run test:full` runs everything (reflection only). Verify a task with the test files you touched; the orchestrator runs Done-when itself. Copy a neighbouring test's setup: server tests spawn server.mjs on a free port with `CW_DATA_DIR` = temp dir, scheduling tests run `createOrchestrator` with a fake `query`, CLI adapters use stubs in test/fixtures/, UI tests use playwright-core, worker tests run worker.mjs against an in-process hub.
- Times: events carry `until` (epoch s); app.js `withUntil` formats in the browser. Never format times on the server except in logs.
- AUDIT.md items get `**Fixed**` + a one-line note; UI-REVIEW.md rows are marked fixed in place.
- Mobile: follow Apple HIG (apple-design skill). Keyboard: app.js `syncKeyboard` sets `--kb` + `html.kb-open`. Modals need `grid-template-columns: minmax(0, 100%)`; test/ui-away.test.mjs checks every modal fits 375×667 and 390×844. Touch targets (44px) go in `@media (pointer: coarse)` blocks (test/ui-mobile-targets.test.mjs). Filled buttons use `--accent-strong`; test/ui-contrast.test.mjs asserts ≥ 4.5:1 in both themes.
- macOS shell scripts must parse under bash 3.2 (`~/.local/opt/bash-3.2.57/bin/bash`, test/install-macos-bash32.test.mjs). Tests load installer functions with `AGENT_ORCH_INSTALLER_NO_MAIN=1`.

## Decisions (beyond BRIEF.md)
- Subscriptions only: API_ENV stripping in server.mjs is what enforces it. Never weaken that.
- Local branch `backup/pre-agent-orch` must never be pushed. Local `claude/*` branches are the owner's snapshots: never land or delete them unasked.
- `after` is for TRUE prerequisites only (cancelling cascades). Use `files` to keep parallel work apart.
- System font stack only. No benchmark ranking of models, ever.
- Computer work follows AGENTIC.md's rollout (files-only workspace first). The owner cancelled the Gmail connector (#259, 2026-09-28); don't queue connectors until asked.

## Gotchas
- This checkout IS the live app. Never restart/kill it or call `POST /api/restart-when-idle` on port 3000. Test instances MUST use another port and `CW_DATA_DIR=$(mktemp -d)`. Server/orchestrator edits go live only on restart ("Restart when idle" banner): a failing Done-when may be stale running code, and new DB tables don't exist until then.
- The verifier runs every command-like backtick snippet in Done-when, joined with ` && `; `>` and `curl` are refused. Absence checks use `! grep …`. A `|` inside a quoted grep pattern is regex, not a pipe.
- /tmp is a small tmpfs with a per-user quota (EDQUOT); run heavy tests with `TMPDIR=` on the home disk. Chromium puts a Unix socket (≤107 bytes) in TMPDIR; bin/test.mjs falls back to ~/.cache when the path is too long.
- test/helper-kill.test.mjs is racy under load and can leave `test/fixtures/helper-parent.mjs` running, hanging `npm test` and the shared test lock. Kill that pid.
- `bin/agent-smoke.mjs` and `bin/orch-e2e.mjs` cost quota; never send Claude logout (`confirm: true`) in tests. Tooltips that hide on scroll flicker under Playwright `hover()` on this 1-core box.
- bash 3.2: functions shipped via `bash -c "$(declare -f)"` must use `cmd <<EOF`, not `cat <<EOF | cmd`. Under `set -u` an empty `"${arr[@]}"` or `"${BASH_SOURCE[0]}"` is unbound. No `declare -A`, `mapfile`, `${x,,}`, `|&`, `;;&`, `local -n`.
- Other sessions and orchestrator auto-commits touch the live checkout at once: re-read before editing, keep shared test edits minimal. A branch failing in files you didn't touch is usually a stale snapshot base: fast-forward the worktree to main and re-run.
- The owner's MacBook Air worker (8 GB, 4 slots) has a nearly full disk; a worker job takes ~1.5 GB, so low disk drains it until 3 GB is free again.
