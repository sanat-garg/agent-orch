# Project Context

_Durable knowledge for every session. History: JOURNAL.md. Bugs: AUDIT.md. Mobile HIG findings: UI-REVIEW.md. Cluster design: CLUSTER.md. Computer-work agents (gate, connectors, browser): AGENTIC.md. CLI flags and stream formats: AGENTS.md. Each module opens with a header comment: read it before changing the module._

## Architecture (head)
- `server.mjs`: node:http + `ws`; login/sessions (cookie `__Host-cw_session` over HTTPS, `cw_session` on http), chat via the Agent SDK `query()`, serves `public/`. PORT 3000. Chat runtimes end only via `retireRuntime` (runtimes.mjs). Refuses to start on a paired worker (role.mjs) unless `AGENT_ORCH_WORKER_JOB` is set.
- `orchestrator.mjs`: node:sqlite DB `data/orchestrator/agent-orch.db`; planner / work / reflection loop; `runAgent()` wraps adapters with timeout + run log; prompts inline. `createOrchestrator({config})` overrides CFG in tests. Deps: `task_deps` + `all_deps` view. Queue order = `tasks.position` per project; plan/reflect/user tasks and deadlines < 24 h jump ahead. Done-when runs through `taskrun.mjs extractCommand`.
- `agents.mjs`: adapter registry (`AGENTS`, `runAgentCli`): claude (SDK) and codex (`codex exec --json`) only, sharing `spawnJsonl`. Normalisers must never emit `{}`/`""` when the native event had data (test/empty-events.test.mjs). `agentStatus` (on PATH + logged in, cached 60 s) gates routing.
- `models.mjs`: model lists come only from each CLI (`discoverModels`), cached `<DATA>/models.json`, rediscovered once a day or after a sign-in change. Never hardcode a model list.
- `helpers.mjs`: every discovery/limit/sign-in helper runs through `runHelper`/`helperOut`/`runHelperSync`/`claudeHelperSpawn` (own process group, SIGTERM→SIGKILL, watchdog, single-flight). Never add raw execFile/spawnSync helpers.
- Routing `resolveRoute`: task agent/model → project route → global route → Claude on project.model. Unavailable agents fall back to Claude with `tasks.route_note`. Sessions resume only on the agent and node that made them.
- Limits are per agent (`limitScope`, `blockedUntilFor(agent)`). Nothing polls limits: only the usage card's refresh (`POST /api/limits/:id/refresh`) checks one agent; Claude runs report limits as they go. `usage.mjs` = `<DATA>/metrics/usage.jsonl`; `health.mjs` builds Connections `health`.
- Delegation `delegate.mjs`: a task moves only if its `tasks.fallbacks` snapshot is non-empty; `nextModel` picks the first entry that is connected, listed, unblocked and under 90% of a window. Lists: `convo.fallbacks` per chat, kv `reflect_settings` for reflection. Moves append to `tasks.moves`; UI text only from app.js `modelStatus(task)`.
- Owner controls: pause/resume/handoff set `stopIntents`, applied by `applyStopIntent` only when the run ended requeued. Paused keeps session + worktree and pins agent/model. Planner `planTurn` runs on the chat's agent; owner messages during a plan task go through `deferMessage`; a paused project keeps its queued plan task until resumed.
- Worktrees (worktrees.mjs): work tasks run in `<repo>/../.agent-orch-worktrees/<repo>-task-<id>` on branch `agent-orch/task-<id>`. Only `mergeTask` touches the main tree, under `serialGit` (squash, rebase, ff-only, push); a rebase conflict → `needs_integration` + an integrator task. JOURNAL.md merges `merge=union`. `tasks.files` (NULL = everything) + `filesOverlap` decide what may run in parallel.
- Slots (parallel.mjs): kv `parallel_settings` `{parallelTasks, controllerWork, maxTasks, controllerBrowser}`. The controller runs 2 only with MemAvailable > 2.5 GB and swap < 25% (`AGENT_ORCH_MEMINFO` = fixture in tests); < 800 MB → no claims; `memGuard` aborts the newest work task under 300 MB. `capacityView` sums controller + worker slots.
- `resources.mjs`: /proc snapshot every 10 s and the reaper (`AGENT_ORCH_REAPER=on|dry|off`; never live server/task/chat/terminal processes; ownership via env `AGENT_ORCH_OWNER`).
- Review breaks: `kind='review'` tasks never run; `armCheckpoints()` moves one whose deps are done to `awaiting_review`; approve → done; request-changes queues a fix task into its deps.
- `connections.mjs`: web sign-in runs each CLI's login in tmux (socket `agent-orch-login`, killed on every boot) and scrapes the pane; `remote-login.mjs` proxies it to a worker (`?node=<id>`).
- `extensions.mjs` (Settings → Skills & tools, `public/ext.js`): skills and subagents go where the CLIs find them; MCP servers and personas in `<DATA>/extensions/` (0600, secrets masked). MCP reaches runs via files, never argv. Persona = `convo.persona`, added via `withPersona` to every system text. Workers get the same bundle per job (`ext.sync`/`job.start.ext` carry a hash; `applyBundle` touches only entries in its `extensions/synced.json`).
- Browser capability (`browser.mjs`): tasks with `capabilities: ["browser"]` (+ `tasks.browser_identity`) get the pinned `@playwright/mcp` via `ext.mcpRun(agent, {browser, gate})` on profile `~/.agent-orch-browser/profiles/<identity>`. `place`: workers with `inventory.browser.capable` + feature `approvals`, controller only with `controllerBrowser`, one running task per identity. Worker `ensureBrowser` installs Playwright Chromium (`AGENT_ORCH_WORKER_BROWSER=off|check|install`).
- Approval gate (`gate.mjs`, `gate-proxy.mjs`, head-side `approvals.mjs`): the Playwright MCP and connectors (stdio MCP servers with an `outbound` tool list) run behind a stdio proxy that classifies calls read/draft/outbound, holds outbound ones for the owner and logs everything. Proxy ↔ host talk only through files in the run's gate dir (`<DATA>/gate/run-<runId>`, worker `~/.agent-orch-worker/gate/job-<id>`); workers relay via job events + `job.approval`. Table `approvals`, log `<DATA>/audit/<task>.jsonl`, kv `gate_settings`. Held time doesn't count toward the task timeout.
- Live browser view (`browser-live.mjs`, `browser-view.mjs`, `public/browser.js`, sidebar globe → Browser sheet): one Chromium per profile with a DevTools port, shared by viewers and the run's MCP shim `bin/browser-mcp.mjs`. Take-over = file `<browserRoot>/control/<id>.takeover`: the shim holds every `tools/call` while it exists. Workers serve it via `screen.*` frames. `AGENT_ORCH_BROWSER_HOME` moves the profiles root in tests.
- `stats.mjs`/`public/stats.js` (raw records, sliced in the browser), `media.mjs` (screenshots by sha256, `bin/shot.mjs`), `github.mjs` (gh wrapper; every project gets a private repo on `origin`).
- `public/`: vanilla JS SPA (app.js ~7k lines, marked + dompurify), PWA. Shared helpers: `toast`, `renderFallbackEditor`, `withUntil`, `fmtDur`. Check for name clashes before adding functions (a later declaration silently wins). #orchBar stays minimal (dot + word + Queue + Pause); everything else is in the gear's Settings sheet.
- Live setup: systemd units agent-orch, agent-orch-shell (ttyd 127.0.0.1:7682, Caddy `/shell/`), agent-orch-tmux. `data/` (gitignored) holds auth, convos, metrics, logs, DB, run logs.

## Architecture (cluster)
- `cluster-protocol.mjs`: wire format, validators, pairing/token helpers, `FEATURES` (newer frame types go only to peers listing the feature in hello/welcome), `WORKER_ACCEPTS` (the only frames a worker acts on). Change the protocol here first; CLUSTER.md follows the module.
- `cluster.mjs` (hub): `nodes` + `pairings` tables, bearer-token WS at `WS_PATH`, local node id `controller`. `HEALTH` auto-drain rules (disk < 2 GB, 3 drops / 30 min) set `drain_reason`/`drained_at`; only the owner undrains (sets `health_ack`). Workers self-update once idle when > 20 commits behind. `CW_CLUSTER_HEARTBEAT_MS` shortens liveness in tests. `power.mjs`: Mac battery/sleep policy.
- `worker.mjs` (compute-only: `pair`/`run`/`status`/`limit`), home `~/.agent-orch-worker` (`AGENT_ORCH_WORKER_HOME`): `repos/` bare blob-less caches (pruned after 14 idle days), `worktrees/`, `deps/<lockfile-hash>/node_modules` symlinked into worktrees, `npm-cache/`, `gate/`. Must never import server/orchestrator/cluster/runtimes (shared code goes in taskrun.mjs; test/compute-only.test.mjs walks the import graph). Every job runs through `<home>/run` (systemd scope or nice; tests set `AGENT_ORCH_WORKER_LIMITER=nice`). `worker.sock` is the only listener allowed. `node-metrics.mjs`: `<DATA>/metrics/nodes/<id>.jsonl`.
- Placement (orchestrator `place`/`runRemote`/`remoteJob`): a work task goes to the free online worker with the agent signed in and most headroom (`nodeCap`), else the controller; `tasks.run_on` pins one. Plan/reflect/integrators, tasks with a live local worktree and projects without an https/ssh origin stay local. On job.done the head fetches `agent-orch/task-<id>` (tip must equal job.done.sha) and runs `mergeTask`. Lost jobs (grace `nodes.grace_ms`) requeue with `[lost]` + a handoff from the pushed WIP branch; remote tasks survive a head restart (`adopt`).
- Install + UI: Machines → "Add machine" (app.js `AM`) shows the `curl …/install/worker-{linux,macos}.sh | bash -s -- …` line (served pre-auth). macOS runs the worker as user `agentorch` from a LaunchDaemon. Machines view: one card per node (`max_slots` 0 = Auto, drain, remove), diagram `CA`, node modal `ND`.

## Conventions
- ESM `.mjs`, no build step, no framework, minimal deps. Match the terse style and comment density.
- Tests: `npm test` (bin/test.mjs, private TMPDIR, one suite per machine via flock) runs only the test files the diff from main can reach (bin/test-select.mjs); `npm test -- --list` shows the pick, `npm test -- test/x.test.mjs` runs named files, `npm run test:full` runs everything (reflection only). Verify a task with the test files you touched; the orchestrator runs Done-when itself. Server tests spawn server.mjs on a free port with `CW_DATA_DIR` = temp dir (`CW_NO_ORCHESTRATOR=1` = read APIs only). Scheduling tests run `createOrchestrator` in a child with a fake `query` and `config: { pollMs: 100 }`. CLI adapters use stubs in test/fixtures/. Browser tests (test/ui-*.test.mjs) use playwright-core. Worker tests run worker.mjs against an in-process hub with `health: {diskMinBytes: 0}`, `AGENT_ORCH_WORKER_SRC` = a scratch repo, and fake a Mac with `AGENT_ORCH_WORKER_POWER`.
- Times: events carry `until` (epoch s); app.js `withUntil` formats in the browser. Never format times on the server except in logs.
- AUDIT.md items get `**Fixed**` + a one-line note; UI-REVIEW.md rows are marked fixed in place.
- Mobile: follow Apple HIG (apple-design skill). Keyboard: app.js `syncKeyboard` sets `--kb` + `html.kb-open`. Modals need `grid-template-columns: minmax(0, 100%)`; test/ui-away.test.mjs checks every modal fits 375×667 and 390×844. Touch targets go in `@media (pointer: coarse)` blocks, 44px.
- macOS shell scripts must parse under bash 3.2, tested with `~/.local/opt/bash-3.2.57/bin/bash` (bin/dev/build-bash32.sh; test/install-macos-bash32.test.mjs). Tests load installer functions with `AGENT_ORCH_INSTALLER_NO_MAIN=1`.

## Decisions
- Chat and agents run on subscriptions, never API credits (API_ENV stripping in server.mjs). Never weaken that.
- Claude Code and Codex are the only agents; Antigravity, OpenCode, Kiro and Copilot were removed for good.
- Repo is github.com/sanat-garg/agent-orch with fresh history; local branch `backup/pre-agent-orch` must never be pushed.
- `after` is for TRUE prerequisites only (cancelling cascades). Use `files` to keep parallel work apart.
- System font stack only. Delegation = owner-entered fallback lists only; no benchmark ranking.
- Workers are compute-only: terminal status view and local cap are their only local surface.
- Nothing polls the CLIs on a timer: limits on demand, model lists once a day.
- Computer work follows AGENTIC.md's rollout (files-only workspace first). The owner cancelled the Gmail connector (#259, 2026-09-28); don't queue connectors until asked.

## Gotchas
- This checkout IS the live app. Never restart/kill it or call `POST /api/restart-when-idle` on port 3000. Test instances MUST use another port and `CW_DATA_DIR=$(mktemp -d)`. Server/orchestrator edits go live only on restart ("Restart when idle" banner), so a failing Done-when may be stale running code.
- The verifier runs every command-like backtick snippet in Done-when, joined with ` && `; `>` and `curl` are refused. Absence checks use `! grep …`. A `|` inside a quoted grep pattern in a "prints nothing" check is regex, not a pipe (taskrun.mjs blanks quoted text first).
- /tmp is a small tmpfs with a per-user quota (EDQUOT); run heavy tests with `TMPDIR=` on the home disk. Chromium puts a Unix socket (≤107 bytes) in TMPDIR; bin/test.mjs falls back to ~/.cache when the path is too long.
- test/helper-kill.test.mjs is racy under load and can leave `test/fixtures/helper-parent.mjs` running, hanging `npm test` and the shared test lock. Kill that pid.
- Playwright `hover()` scrolls the target into view; tooltips that hide on scroll flicker on this 1-core box (stats.js `wireTips` re-targets instead).
- Claude logout needs `confirm: true`; never send it in tests. `bin/agent-smoke.mjs` and `bin/orch-e2e.mjs` cost quota.
- `#lbView` needs `contain: size`. Don't commit macOS `._*` files.
- bash 3.2: `declare -f` prints `cat <<EOF | cmd` with `| cmd` after the EOF line, so functions shipped via `bash -c "$(declare -f)"` must use `cmd <<EOF`. Under `set -u` an empty `"${arr[@]}"` or `"${BASH_SOURCE[0]}"` is unbound. No `declare -A`, `mapfile`, `${x,,}`, `|&`, `;;&`, `local -n`.
- Other sessions and orchestrator auto-commits touch the live checkout at once: re-read before editing, keep shared test edits minimal. A branch failing in files you didn't touch is usually a stale snapshot base: fast-forward the worktree to main and re-run.
- The owner's MacBook Air worker has a nearly full disk (a few GB free of 245 GB); a worker job takes ~1.5 GB (worktree + deps + Chromium). Low disk auto-drains it and nothing undrains it.
